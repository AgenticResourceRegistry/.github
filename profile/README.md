# Agentic Resource Registry

Agentic Resource Registry is a self-hosted, Apache 2.0 registry for sharing coding agent resources. Define the scope and share your Skills, MCP servers, and Agents with your peers.

Stop scattering skills, MCP servers, and other coding agent resources across git repos. Publish them once, install them into any harness, and see how they are used.

[Get started](https://github.com/AgenticResourceRegistry/AgenticResourceRegistry)
